# 大语言模型提示词
* **2026-10-21：每日医学影像科研简报**  
  搜索最近24小时至数日内新发布或有重大更新的医学图像分析、医学图像分割、深度学习 医学Foundation Models以及Agent 相关论文（包括 arXiv 和重要会议/期刊）。用中文生成有筛选价值的每日科研简报，专业术语保留英文。重点推荐不超过5篇最相关的论文，为每篇提供论文标题、发表或更新日期、原始来源链接、核心创新点、方法概要、潜在局限，以及与基于深度学习的医学图像分析研究的关系；区分论文作者声称与独立判断，不确定的细节明确说明。工具更新简要说明变化及科研工作流价值，并给出可靠的官方链接。优先比较过去已推送的简报，尽量避免重复；如需再次介绍此前论文，必须说明新进展及重提原因。如当日无值得推荐的论文或工具变化，简要说明，不凑数。
